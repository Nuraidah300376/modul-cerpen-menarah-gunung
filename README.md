# Modul Pembelajaran Kendiri Cerpen: Menarah Gunung

Modul pembelajaran kendiri interaktif untuk mata pelajaran Kesusasteraan Melayu Komunikatif (KMK), STPM Tingkatan Enam.

Kandungan merangkumi sinopsis, tema dan persoalan, watak dan perwatakan, unsur plot, analisis latar, amanat dan pengajaran, aktiviti kendiri, kuiz serta pencapaian pelajar.

## Penerbitan GitHub Pages

Letakkan fail `index.html` modul asal pada direktori utama (root) repositori. Kemudian pilih **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Nota: Kandungan asal modul pembelajaran hendaklah dikekalkan. Penggunaan bahan tertakluk pada kebenaran pemilik kandungan dan hak cipta sumber berkaitan.
